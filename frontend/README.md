# 耳コピDI — Frontend Web App

ベース練習の耳コピを補助するWebアプリ。React + TypeScript + Vite。ログイン不要、ブラウザのローカルストレージのみで動作する単体のWebアプリ（バックエンド不要）。

見た目はスタジオ機材（ラックユニット/DIボックス）をモチーフにしたダークテーマ。各機能はパネルセクション（TRANSPORT / TONE / LOOP / TUNER・SCOPE / NOTES）に分かれ、数値表示はドットマトリクス風のLED表示（`src/styles.css`）。

## セットアップ

```bash
npm install
```

## 開発サーバー起動

```bash
npm run dev
```

## テスト実行

```bash
npm test          # 一回実行
npm run test:watch
```

## ビルド

```bash
npm run build
```

## 主な機能
- ローカル音声ファイル（mp3/wav/m4a）読み込み、低音域強調EQ、音程保持スロー再生、サンプル精度に近いA-Bループ、音名/周波数表示、波形/スペクトログラム表示
- YouTube埋め込み再生（再生速度変更、簡易A-Bループ）。**タブの音声を解析用に共有**すると、音程表示・波形表示・コード推測（参考）も使えるようになる（聞こえる音自体は変わらない＝EQは依然として対象外。ブラウザのタブ共有ダイアログで許可が必要）
- **マイク入力モード**: YouTube等を別端末・スピーカーで再生しつつ、マイク経由でこのアプリに音を入力し、低音域EQ・音程表示・波形表示・コード推測を使える（再生速度変更・ループは対象外。ヘッドホン推奨、スピーカーだとハウリングの原因になる）
- **弦・フレット表示**: 検出した音名から、4弦ベース（E-A-D-G）の何弦・何フレットで弾けるかを音楽理論の計算で表示
- **コード推測（参考）**: 複数の音の周波数成分からコード（メジャー/マイナートライアド）を推測。精度は参考程度（フルミックスの音源では誤判定が増える）
- **採譜ログ（自動記録）**: リアルタイムで検出した音を、弾くたびに自動でログへ記録（手動でメモを取るには速すぎるため）。「メモにコピー」で手動メモへ転記可能。曲全体を自動でタブ譜化する機能ではない点に注意（技術的に現実的でないため対象外とした）
- 曲ごとのループ区間・メモ・採譜ログの保存（端末のブラウザにローカル保存。ログイン・端末間同期はなし）
