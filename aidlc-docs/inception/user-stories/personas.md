# Personas: 耳コピ補助アプリ

## ペルソナ1: ベース奏者（本人）

- **役割**: コピーバンドでベースを担当。耳コピで楽曲のベースラインを練習している。
- **背景**: ある程度の聞き取り能力はあるが、時間的な制約があり、効率的に耳コピを進めたい。音名（E2, A2等）は読める程度の音楽知識がある。
- **目標**: 練習時間を最大限に活用し、短時間で正確にベースラインを把握したい。
- **利用環境**:
  - 自宅PC: 事前にじっくり準備（曲のループ区間決め、メモ作成）
  - スタジオ/練習の場のスマホ: サッと確認・練習（自宅で作った設定を引き続き使う）
- **ペインポイント**:
  - 低音域が他の楽器の音に埋もれて聞き取りづらい
  - 原曲の速度のままだと速いフレーズが聞き取れないが、音程が変わるとピッチが分からなくなる
  - 同じ区間を何度も聞きたいが、毎回手動で頭出しするのが面倒
  - 自宅で用意したループ区間やメモが、スタジオのスマホで見られないと二度手間になる
- **単独ユーザー**: 他のユーザーと機能やデータを共有する必要はない。
