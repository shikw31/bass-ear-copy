# Performance Test Instructions

## 適用性
個人用ツール（単独ユーザー、Requirements Analysis確定）のため、正式な負荷テスト・ストレステストはスコープ外と判断する（Resiliency Baseline拡張も無効化済み）。

NFR Requirementsで定義した目安値のみ、実利用の中で確認する:

| 項目 | 目安 | 確認方法 |
|---|---|---|
| EQ/タイムストレッチの処理遅延 | 50ms以内（知覚できないレベル） | 実際にスライダーを操作し、音の反応に遅延を感じないか確認する |
| ピッチ検出の更新頻度 | 10〜20Hz | 音程表示がスムーズに更新されるか目視確認する |
| 波形描画 | 30fps程度 | 波形表示がカクつかないか目視確認する |
| フロントエンド初期ロード | 3秒以内 | ブラウザの開発者ツール（Network/Performanceタブ）で計測 |
| バックエンドAPI応答 | 1秒以内（Cold Start込み） | `curl`で応答時間を計測（`curl -w "%{time_total}\n" -o /dev/null -s <URL>`） |

これらは体感・簡易計測で十分とし、JMeter/k6等の専用負荷テストツールの導入は行わない。
